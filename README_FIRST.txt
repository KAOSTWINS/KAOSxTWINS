PUBLISH TO YOUR EXISTING GITHUB PAGES WEBSITE
1. Keep a backup copy of your current repository and its index.html.
2. Extract this ZIP. Copy index.html into the repository ROOT, replacing
   the old index.html.
3. Copy the 'assets/unholy-alliance/' folder into the matching repository
   assets/ folder. Do not rename the MP3s or move the folder.
4. Commit and push with GitHub Desktop / git. GitHub's web upload limit
   may block the large index.html, so a desktop Git workflow is preferable.
5. After GitHub Pages finishes deploying, refresh the site and visit:
   https://kaostwins.github.io/KAOSxTWINS/#bot/alliance
   https://kaostwins.github.io/KAOSxTWINS/#bot/dragon
   https://kaostwins.github.io/KAOSxTWINS/#bot/stormfall
6. Test a song by clicking ▶ in the playlist. If the player says it
   cannot load the file, check that assets/unholy-alliance/music/ uploaded.

NOTE: Files are prepared, not automatically published to your GitHub account.
The website includes large inline artwork inherited from the previous build.
If a hosting service enforces per-file size limits, migrate inline images
into separate assets in a separate optimization pass.
