HOW TO PUBLISH
1. Back up your existing GitHub repository or download its current files.
2. Unzip this package.
3. Copy index.html into the ROOT of your current KAOSTWINS GitHub Pages repository,
   replacing only the previous index.html.
4. Copy the ENTIRE assets/packed/ folder into the repository's assets directory.
   Keep the packed filenames and paths unchanged.
5. DO NOT delete or replace the rest of your existing assets/ or other site files.
6. Commit/push the changes and allow GitHub Pages to deploy.
7. Open https://kaostwins.github.io/KAOSxTWINS/#bot/ezra and test:
   - Four ex photos and their click-to-open case files
   - 'Don't Listen' cassette audio, native player and liner notes
   - The random Ezra excuse button
   - The link to the Dreamjourney bot
   - The 18+ After Dark gallery and older bot pages
